# Hireko AI Recruiter Plugin for Antigravity

Connect Antigravity to Hireko recruiter services for candidate interview analytics, AI interview invitation generation, candidate scorecards, and talent search.

## Features
- **Candidate Analytics**: View completed and pending interview counts and pass rates.
- **AI Interview Links**: Generate candidate interview links with auto-detected tenant jobs.
- **Search & Scoring**: Match candidates against job descriptions using vector search scores.
